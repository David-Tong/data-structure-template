# data-structure-template
Copy-paste ready data structure templates for competitive programming.

## Folder Structure

```
data-structure-template/
├── python/        # Python 2 compatible templates
├── python3/       # Python 3 templates
└── README.md
```

## Design Principles

- Each file is **self-contained** — copy one file into your project, no extra imports needed.
- Each category folder (e.g. `segment_tree/`) groups related structures in a single file where practical.
- A paired `*_example.py` shows concrete usage for each template file.

## Languages

| Folder | Version | Notes |
|--------|---------|-------|
| [`python/`](python/README.md) | Python 2 | Compatible with Python 2.7 |
| [`python3/`](python3/README.md) | Python 3 | Uses type hints and Python 3 idioms |
